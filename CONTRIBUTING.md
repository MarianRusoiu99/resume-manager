# Contributing to Resume Manager

We welcome contributions! This document outlines how to contribute to the project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/resume-optimizer.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`

## Development Setup

See the [README.md](./README.md) for setup instructions.

## Code Standards

- Follow existing code style and conventions
- Run `npm run lint` before committing
- Write tests for new features

## Submitting Changes

1. Push your changes to your fork
2. Open a pull request against the main branch
3. Describe your changes and why they're needed

## Reporting Issues

Use GitHub issues to report bugs or suggest features.
