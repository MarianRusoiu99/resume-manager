## Codebase Patterns
- Use `withTransaction<T>()` from `@/lib/db/transaction` for atomic multi-step database operations
- Prisma's interactive transaction pattern is: `prisma.$transaction(async (tx) => { ... })`
- TypeScript checks pass via `npx tsc --noEmit`; `npm run build` may fail on unrelated React/Next.js issues
- Use `acquireLock`/`releaseLock` or `withLock` from `@/lib/cache/distributed-lock` for distributed locking
- RedisCacheProvider exposes `getClient()` for low-level Redis operations like SET NX EX
- Import test utilities from `@/__tests__/utils` or `@/lib/test` for factories and mocks
